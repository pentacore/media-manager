# Dependencies

## New production packages need the owner's approval
Do not add a new package to `require` in `composer.json` or to `dependencies` in `package.json` without the owner's approval. Ask first, and record each approval below with its date in the same commit that adds the package. Development packages (`require-dev`, `devDependencies`) and version updates of existing packages need no approval. Every production package already installed on 2026-11-23 counts as approved.
